지난 엿새 동안 AI 도구 쪽의 가장 쓸모 있는 신호는 에이전트에 일을 맡기는 구체적 방식이었습니다. 기존 코드를 참조로 주는 프롬프트 사례가 나왔고, 병렬 세션을 관리하는 도구도 함께 등장했습니다.

반면 에이전트가 강의 자료를 지운 사고와 마이크로소프트 365 장애는 안전장치의 필요를 다시 드러냈습니다. 부수 신호로는 젠슨 황(Jensen Huang)의 엔비디아 CEO 사임 소식이 있었지만, 도구 사용법과는 거리가 있습니다.

## 목차
1. 기존 플러그인을 참조로 주면 Claude가 새 플러그인을 짓습니다
2. 병렬 에이전트는 기다리는 세션을 보여주는 장치가 필요합니다
3. 에이전트에 쓰기 권한을 주기 전에 백업과 승인부터 챙겨야 합니다
4. 프로토타입은 컴포넌트 단위로 나눠 맡길 때 품질이 오릅니다
5. 굵은 헤드라인보다 손에 잡히는 사용 사례가 실속입니다

## 1. 기존 플러그인을 참조로 주면 Claude가 새 플러그인을 짓습니다

사이먼 윌리슨(Simon Willison)은 11월 15일 **datasette-maplibre 0.1a0**을 공개했습니다. 이 플러그인은 Datasette용 지리 공간 도구입니다. 지도 라이브러리 MapLibre GL과 무료 벡터 지도 서버 OpenFreeMap을 묶었습니다. [출처](https://simonwillison.net/2026/Nov/15/datasette-maplibre)

구현의 대부분은 Claude Fable 5.2에 보낸 프롬프트 하나로 끝났습니다. 그는 자신의 기존 플러그인 두 개를 참조로 지정했습니다. datasette-cluster-map과 datasette-leaflet-geojson입니다. 여기에 로컬 OpenFreeMap 데모 HTML 파일을 더하고, 두 플러그인의 기능을 합치라고 요청했습니다.

이 프롬프트의 핵심은 백지에서 시작하지 않는다는 점입니다. 이미 동작하는 코드와 데모 파일을 주면 모델이 기존 구조와 관례를 따르기 쉬워집니다. 프롬프트에는 "be creative and think outside the box"라는 주문도 들어갔습니다.

그 결과 요청하지 않은 기능도 붙었습니다. GeoJSON 도형을 먼저 SVG로 미리 보여주고, 화면에 들어올 때만 WebGL로 렌더링하는 방식입니다. Claude는 Datasette Lite에서 도는 데모도 만들었습니다. 이 데모는 Pyodide와 웹어셈블리(WebAssembly)로 브라우저 안에서만 동작합니다.

같은 날 나온 Datasette 1.0a43도 Claude Fable 5.2의 도움을 크게 받았습니다. 이번 버전으로 1.0 마일스톤은 **53%** 완료됐습니다. 핵심 변경은 출력 렌더러의 스트리밍 지원입니다. [출처](https://simonwillison.net/2026/Nov/15/datasette)

기본 CSV와 TSV 내보내기가 이제 스트리밍 방식으로 동작합니다. 플러그인은 새 `Response.stream()` 메서드로 테이블의 모든 행을 흘려보낼 수 있습니다. 따라서 큰 테이블을 내보낼 때 메모리 부담이 줄어듭니다.

자바스크립트 없이 페이지 전환을 매끄럽게 만든 방식도 눈여겨볼 만합니다. 윌리슨은 아래 CSS를 넣고, 패싯과 테이블 요소에 `view-transition-name`을 지정했습니다.

```css
@media (prefers-reduced-motion: no-preference) {
  @view-transition { navigation: auto; }
}
```

미디어 쿼리로 감쌌기 때문에 움직임 줄이기를 켠 사용자에게는 효과가 적용되지 않습니다. 이 설정만으로 사파리와 크롬에서 여러 페이지 앱이 단일 페이지 앱(SPA)처럼 느껴집니다.

1.0a43에는 보안 수정도 들어갔습니다. 비공개 저장 쿼리의 제목과 SQL이 노출될 수 있던 문제입니다. 다만 쿼리 실행까지 허용되지는 않았습니다.

안정 버전용으로는 **Datasette 0.65.6**이 별도 보안 수정을 담아 나왔습니다. 대상은 이름과 다른 route로 등록한 데이터베이스입니다. 접근이 거부된 사용자도 `/<route>.db` 주소에서 파일을 내려받을 수 있었습니다. [출처](https://simonwillison.net/2026/Nov/15/datasette-2)

따라서 사용자 정의 라우트와 접근 권한을 함께 쓰는 운영 인스턴스라면 0.65.6으로 올려야 합니다.

datasette-apps 0.4a0은 앱 사이를 잇는 링크 기능을 더했습니다. Datasette Apps는 Datasette 안에서 도는 샌드박스 HTML 앱입니다. Claude 아티팩트(Artifacts)와 비슷하지만, 내 데이터에 SQL을 직접 실행할 수 있습니다. [출처](https://simonwillison.net/2026/Nov/15/datasette-apps)

URL의 `#` 프래그먼트로 값을 넘기면 앱이 이를 읽어 동작합니다. 지원하는 URL 형식은 Datasette Agent에 전달되므로, 에이전트가 서로 연결되는 앱을 함께 작성할 수 있습니다. 예를 들어 검색 앱의 결과마다 상세 보기 앱으로 가는 링크를 달 수 있습니다.

강의에서는 참조 코드와 결합 요청, 창의성 주문으로 이뤄진 이 프롬프트를 그대로 실습 예제로 쓸 수 있습니다. 개발에서는 기존 자산을 참조로 넘기는 습관이 새 기능의 초안 작성 시간을 줄여 줍니다.

## 2. 병렬 에이전트는 기다리는 세션을 보여주는 장치가 필요합니다

해커 뉴스(Hacker News)에 올라온 제목에 따르면, Anthropic은 Claude Code의 Projects를 개편했습니다. 병렬 AI 워커가 돌도록 바꾼 것입니다. 원문 주소에도 '재설계(redesigned)'라는 표현이 들어 있습니다. [출처](https://claude.com/resources/articles/projects-redesigned)

해당 글은 해커 뉴스에서 73점과 댓글 72개를 받았습니다. 다만 수집된 정보에는 활성화 방법과 명령, 설정이 빠져 있습니다. 따라서 워크플로를 바꾸기 전에 원문에서 사용법을 먼저 확인하는 편이 안전합니다.

같은 기간 GeekNews의 Show GN에는 **agent-monitor**가 올라왔습니다. 여러 Claude Code와 Codex 터미널 세션을 추적하는 macOS 메뉴바 앱입니다. [출처](https://news.hada.io/topic?id=37251)

메뉴바에 '2/5'가 표시되면 다섯 세션 중 두 개가 응답을 기다린다는 뜻입니다. 기다리는 세션이 없으면 숫자가 흐려집니다. 숫자를 누르면 세션 목록이 열리고, 답이 필요한 세션이 맨 위에 옵니다.

개발자는 승인 프롬프트에서 멈춘 세션을 뒤늦게 발견하는 일이 반복돼 이 앱을 만들었습니다. 여기서 병렬 실행의 병목이 드러납니다. 병목은 모델 속도가 아니라 사람의 응답 대기입니다.

따라서 세션 수를 늘리기 전에 대기 상태를 한눈에 보는 장치부터 갖추는 것이 좋습니다. 또한 승인이 자주 필요한 작업과 혼자 끝낼 수 있는 작업을 나눠 배치하면 유휴 시간이 줄어듭니다.

강의 실습에서는 세션을 두세 개만 동시에 돌리게 하는 방식이 적합합니다. 수강생은 대기 상태를 확인하는 습관을 먼저 익힌 뒤 규모를 늘릴 수 있습니다.

## 3. 에이전트에 쓰기 권한을 주기 전에 백업과 승인부터 챙겨야 합니다

톰스하드웨어(Tom's Hardware)는 Claude 에이전트가 쪽 번호 수정만 요청받고 파일을 지운 사례를 전했습니다. 한 법학 교수의 강의계획서 전체와 **1년 치 강의 노트**가 삭제됐습니다. 제목에 따르면 에이전트는 자신의 부주의 탓이라고 인정했습니다. [출처](https://www.tomshardware.com/tech-industry/artificial-intelligence/rogue-claude-ai-tasked-with-renumbering-pages-accidentally-deletes-law-professors-entire-syllabus-one-year-of-lecture-notes-youre-right-to-be-angry-i-deleted-your-files-through-my-own-carelessness-humbled-agent-admits)

어떤 Claude 제품을 어떤 권한으로 썼는지는 알려지지 않았습니다. 그래도 교훈은 분명합니다. 작업이 사소해도 위험까지 작아지지는 않습니다.

쪽 번호 수정처럼 단순한 작업에도 쓰기와 삭제 권한이 따라옵니다. 따라서 에이전트를 붙이기 전에 폴더를 Git으로 관리하거나 백업을 떠 두는 것이 기본입니다. 또한 승인 전에 에이전트가 제안한 파일 작업 목록을 읽고, 삭제나 덮어쓰기가 보이면 그 자리에서 멈춥니다.

에이전트의 권한은 결제로도 넓어지고 있습니다. 오픈AI는 **ChatGPT Wallet**을 발표했습니다. ChatGPT Work와 Codex, dots의 에이전트가 구매를 마칠 수 있게 하는 기능입니다. [출처](https://openai.com/index/introducing-chatgpt-wallet)

구매마다 사용자 승인이 필요하고, 기존 카드 보호 장치를 그대로 씁니다. 반면 설정 방법과 지원 카드, 가격, 제공 범위는 발표문에 나오지 않습니다. 따라서 실제로 쓰기 전에 원문을 확인하고, 승인 단계를 습관처럼 넘기지 않도록 주의해야 합니다.

마이크로소프트 365는 24시간 넘게 전 세계에서 장애를 겪었습니다. 마이크로소프트는 앞서 진행한 네트워크 용량 업그레이드를 원인으로 지목했습니다. 11월 14일 새벽 5시 기준으로도 Copilot 365 Chat이 응답하지 않을 수 있었습니다. [출처](https://www.itworld.co.kr/article/4248815/%eb%84%a4%ed%8a%b8%ec%9b%8c%ed%81%ac-%ec%9a%a9%eb%9f%89-%ec%97%85%ea%b7%b8%eb%a0%88%ec%9d%b4%eb%93%9c%ea%b0%80-%eb%b6%80%eb%a5%b8-%eb%a7%88%ec%9d%b4%ed%81%ac%eb%a1%9c%ec%86%8c%ed%94%84%ed%8a%b8-365.html)

NCC Group의 매트 헐(Matt Hull)은 장애를 틈탄 사칭 공격을 경고했습니다. 공격자가 마이크로소프트나 사내 IT를 사칭해 비밀번호 재설정이나 다중 인증(MFA) 승인을 요구할 수 있습니다. 따라서 예상하지 못한 연락은 공식 채널로 다시 확인해야 합니다.

다른 칼럼에 따르면 Anthropic도 같은 기간 자사 서비스 문제를 보고했습니다. 노드VPN의 CTO는 단일 업체 없이도 업무가 이어지는지 시험해 보라고 조언했습니다. [출처](https://www.itworld.co.kr/article/4248779/%eb%a7%88%ec%9d%b4%ed%81%ac%eb%a1%9c%ec%86%8c%ed%94%84%ed%8a%b8-365-%ec%9e%a5%ec%95%a0%ea%b0%80-%eb%93%9c%eb%9f%ac%eb%82%b8-%eb%8b%a8%ec%9d%bc-%ec%97%85%ec%b2%b4-%ec%9d%98%ec%a1%b4%ec%9d%98-%ec%b7%a8.html)

강사라면 수업에 쓰는 AI 도구마다 대체 도구를 하나씩 정해 두는 것이 좋습니다. 개발자는 에이전트 작업 폴더의 버전 관리와 백업을 기본값으로 삼으면 사고와 장애를 함께 대비할 수 있습니다.

## 4. 프로토타입은 컴포넌트 단위로 나눠 맡길 때 품질이 오릅니다

쇼피파이(Shopify)의 제품 디자인 스튜디오는 정적인 Figma 화면 대신 작동하는 데모를 만듭니다. 도구로는 OpenAI Codex와 Claude Code를 씁니다. 그 결과 디자이너가 프로토타입을 직접 만들고 시험하는 비중이 커졌습니다. [출처](https://news.hada.io/topic?id=37244)

권장 방식은 복잡한 작업을 한 번에 넘기지 않는 것입니다. 먼저 작업을 개별 컴포넌트로 나눕니다. 그다음 결과를 반복해 검토하면서 의도한 시각 품질과 인터랙션 쪽으로 이끕니다.

쇼피파이는 이 방식으로 관리자 화면을 다듬었습니다. 또한 Sidekick 어시스턴트와 대화하며 상점을 관리하는 방식도 탐색했습니다. 다만 팀은 이 프로토타입을 제품 코드가 아니라 합의를 이끄는 도구로 봅니다.

X는 엔지니어 5명과 AI 코딩 에이전트로 6개월이 안 돼 웹 앱을 다시 만들었습니다. 사용자용과 검색 크롤러용, 링크 미리보기용으로 나뉜 서버 세 개를 하나로 합쳤습니다. [출처](https://news.hada.io/topic?id=37245)

기존 React 클라이언트 렌더링에서는 브라우저가 HTML 껍데기와 자바스크립트를 먼저 받아 실행해야 했습니다. 새 구조는 스트리밍 서버 사이드 렌더링(SSR)으로 첫 응답에 실제 콘텐츠를 담습니다. 또한 브라우저는 서버가 가져온 데이터를 다시 씁니다.

느린 네트워크에서 로그인한 프로필을 측정했을 때, 첫 게시물이 뜨는 시간은 **23.9초에서 2.7초**로 줄었습니다. 페이지당 압축 자바스크립트도 4.1~4.8MB에서 1.3~2.3MB로 줄었습니다. 로그아웃 화면은 전환을 마쳤고, 로그인 화면은 국가별로 적용되고 있습니다.

두 사례에서는 사람이 구조와 품질을 판단하고, 에이전트가 구현량을 맡았습니다. 디자인 강의에서는 Figma 화면 하나를 컴포넌트 서너 개로 나눠 차례로 구현하는 실습을 바로 진행할 수 있습니다.

## 5. 굵은 헤드라인보다 손에 잡히는 사용 사례가 실속입니다

이 기간에는 제목만 굵고 사용법은 비어 있는 신호가 많았습니다. TLDR AI 뉴스레터도 여러 소식을 제목에 올렸습니다. Gemini 4 Hydrogen과 자체 호스팅 Claude 에이전트, Replit의 에이전트 커머스입니다. 그러나 수집된 정보는 제목뿐입니다. [출처](https://tldr.tech/ai/2026-11-13)

오픈AI는 GPT-6 Astra가 표준 모형의 격자 정의 증명을 도왔다고 밝혔습니다. 하지만 모델을 어떻게 썼고 증명을 어떻게 검증했는지는 발췌문에 없습니다. [출처](https://openai.com/index/step-toward-defining-the-standard-model) 오픈AI는 연구 사례를 다루는 과학 블로그도 새로 열었습니다. [출처](https://openai.com/index/our-new-blog-for-science)
