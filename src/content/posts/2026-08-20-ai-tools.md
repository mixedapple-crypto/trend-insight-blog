## 1. Claude Code + GitHub Actions: 환경 제약을 에이전트가 자율 우회한 사례

**Claude Code**의 리서치 모드가 `smolvm`을 비신뢰 코드 샌드박스로 평가하는 과정에서 한 가지 구조적 문제를 만났습니다.

Claude Code 웹 환경에는 중첩 가상화에 필요한 `/dev/kvm`이 없습니다. 에이전트는 여기서 멈추지 않고, `/dev/kvm`을 지원하는 **GitHub Actions**로 자율 전환해 임시 워크플로를 생성하고 실제 테스트 슈트를 직접 실행했습니다. [출처](https://simonwillison.net/2026/Aug/19/smolmachines-untrusted-sandbox)

실전 적용 포인트는 세 가지입니다.

첫째, 사용자 코드 실행 샌드박스가 필요하다면 `smolvm`의 RAM·CPU·네트워크·파일시스템 격리 조합을 먼저 검토하십시오.

둘째, 에이전트에게 실행 환경까지 위임할 때는 **GitHub Actions** 러너를 대안 실행 경로로 명시적으로 허용해 두면 자율 우회 패턴을 안정적으로 활용할 수 있습니다.

셋째, Jeremy Morrell이 정리한 "확장 가능 소프트웨어(Extensible Software)" 개념과 연결됩니다. 핵심 앱은 안정적 확장점만 노출하고, LLM이 사용자의 도메인별 확장 코드를 샌드박스 안에서 생성·실행하게 하면 배포 비용을 크게 낮출 수 있습니다. [출처](https://simonwillison.net/2026/Aug/19/jeremy-morrell)

강의 맥락에서는 "에이전트가 환경을 진단하고 우회한다"는 이 패턴 자체를 실습 예제로 쓸 수 있습니다.

## 2. Asana + Codex: 5년치 레거시 테스트를 2주·1,300만 원에 처리

Asana가 **OpenAI Codex**를 써서 레거시 테스트 인프라를 교체한 사례입니다. 원래 추정 공수는 5년이었으나 실제 소요 기간은 2주, 컴퓨팅 비용은 약 1만 2,000달러(한화 약 1,700만 원)였습니다. [출처](https://openai.com/index/asana)

핵심 방법론은 기존 테스트 패턴과 코드베이스 구조를 Codex에 그대로 입력한 것입니다.

Codex는 수천 개의 테스트 케이스를 수동 재작성 없이 현대적 코드로 변환했습니다. 엔지니어는 라인 단위 수정 대신 아키텍처 설계와 결과 검증에 집중했습니다.

실전 팁입니다.

- 기존 테스트 파일 전체를 컨텍스트로 제공하십시오. 패턴 학습 없이는 품질이 낮아집니다.
- 변환 후 샘플 10~20%를 수동 검토해 회귀(regression) 여부를 확인하십시오.
- 비용 예측은 토큰 단위로 사전에 소규모 파일럿을 돌려 추정치를 잡으십시오.

기술 부채 처리나 대규모 리팩터링 강의의 실증 사례로 직접 인용 가능한 수치입니다.

## 3. Replit Free Mode: GPT-5.6 Luna로 토큰 제한 없이 코드 생성

**Replit**이 Free Mode에 **GPT-5.6 Luna**를 적용해 토큰 제한 없이 작동 소프트웨어를 생성할 수 있도록 했습니다. [출처](https://openai.com/index/replit)

사용법은 단순합니다. Replit IDE에서 모델 드롭다운을 열고 Free Mode를 선택하면 됩니다. 구독 비용 없이 프로토타입을 빠르게 검증할 수 있습니다.

강의 환경에서의 구조적 가치는 수강생 전원이 유료 구독 없이 동일한 환경을 쓸 수 있다는 점입니다.

단, 무료 모드는 모델 선택지가 제한되므로 복잡한 코드베이스 작업에는 유료 티어를 병행 검토하십시오.

## 4. OpenAI 제로 데이터 보존: API에서 프롬프트 저장 차단하는 법

**OpenAI**가 프론티어 모델 API에 **제로 데이터 보존(Zero Data Retention)** 옵션을 제공하기 시작했습니다. [출처](https://openai.com/index/offering-zero-data-retention-for-frontier-models)

활성화하면 입력·출력이 모델 학습이나 개선에 사용되지 않으며, 30일 후 삭제됩니다.

설정 방법은 API 구성 화면에서 해당 옵션을 켜는 것입니다. 이후 요청은 OpenAI의 기본 로깅을 우회합니다.

의료·금융·법률 데이터를 다루는 팀이라면 규정 준수(compliance) 체크리스트에 이 항목을 추가하십시오.

강의에서는 "API 계약 조건이 모델 학습에 미치는 영향"을 설명하는 실례로 쓸 수 있습니다.

## 5. fx·Kimi Code CLI: 터미널 경량 코딩 에이전트 두 종 비교

무거운 터미널 IDE 대신 Unix 철학에 맞는 경량 에이전트 두 종이 나란히 공개됐습니다.

**fx**는 Vercel Labs가 공개한 오픈소스 코딩 에이전트입니다. Zig로 작성됐고 바이너리 크기가 약 7.8 MB입니다. 프로젝트 디렉터리에서 `fx`를 실행하면 됩니다. 빌드 스크립트나 CI/CD 파이프라인에 직접 삽입하기에 적합합니다. [출처](https://news.hada.io/topic?id=32686)

**Kimi Code CLI**는 Moonshot AI가 공개한 오픈소스 터미널 에이전트입니다. 코드 읽기·수정·셸 명령 실행·파일 검색·웹 브라우징을 수행하고, 각 결과를 바탕으로 다음 단계를 자율 선택합니다. Kimi 모델 외 호환 모델도 설정으로 전환 가능합니다. [출처](https://news.hada.io/topic?id=32683)

두 도구의 구분 기준은 명확합니다.

- 파이프라인 삽입·최소 의존성이 목적이라면 **fx**.
- 디버깅·리팩터링·리서치가 혼합된 다단계 작업이라면 **Kimi Code CLI**.

오늘 흐름을 한 줄로 정리하면, AI 코딩 도구는 '생성'에서 '자율 실행'으로 무게중심을 옮기는 중입니다. 환경 제약을 스스로 우회하는 에이전트, 5년 공수를 2주로 압축한 코드 변환, 토큰 제한 없는 무료 IDE까지 — 과장된 기대보다 이 구조 변화를 실측 수치로 검증하는 습관이 실무자에게 더 유효합니다.
